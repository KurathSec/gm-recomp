# Design notes

The project was built in milestones. Each note records what a milestone covered, what
was measured, and what was learned on the way.

| Note | Covers |
|---|---|
| [r0-findings.md](r0-findings.md) | R0: the test corpus, static code discovery, browser feasibility, the guest address space |
| [r1-cpu.md](r1-cpu.md) | R1: the x86 → wasm lifter, the x87 model, SSE, and the CPU differential tests against the host CPU |
| [r2-harness.md](r2-harness.md) | R2: GameMaker 8 runners in the native harness (wasmtime): execution model, virtual time |
| [r3-r5-runtime.md](r3-r5-runtime.md) | R3–R5: the browser runtime, sound, saves, guest threads, Direct3D 9 and shaders, frame pacing and performance |
| [corpus-inventory.md](corpus-inventory.md) | the corpus's modules and every Windows API they import (generated by `importer report`) |
| [instruction-forms.json](instruction-forms.json) | how often each x86 instruction form occurs in the corpus's code |
